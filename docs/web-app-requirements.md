# Design System Hub — Requirements

_最終更新: 2026-04-23_

---

## プロダクトビジョン

**Figmaとコードを繋ぐデザインシステム管理Hub。**

デザイナー・PdM・エンジニアが同じデザインシステムを、
それぞれのツールから参照・編集できる状態を作る。

---

## コアコンセプト

```
プラグイン単体でも使える。
アカウントを作ればチーム全員で同期できる。
```

| モード | 対象 | できること |
|---|---|---|
| Plugin単体 | デザイナー | コンポーネント設定・Figma生成 |
| Web App単体（ログインなし） | 誰でも | デザインシステムをブラウザ上で構築・Storybookのように確認・Figmaや他ツールにエクスポート |
| ログイン同期 | チーム全員 | Plugin + Web Appがリアルタイム同期 |

---

## ターゲットユーザー

**デザイナーと開発者が両方いるチーム**（スタートアップ・デザイン重視のプロダクト）

| ユーザー | 主な使い方 |
|---|---|
| デザイナー | Web App でデザインシステムを構築し、Figma Plugin でキャンバスに反映 |
| PdM | Web App からコンポーネント一覧をStorybookのように閲覧・ドキュメント確認 |
| エンジニア | Web App からコンポーネント仕様・Props・Accessibilityを参照、Markdownダウンロード |

## Web App — UXフロー

### 基本動線

```
Web Appを開く
→ 空の状態（何もない）
→ 「+ コンポーネントを追加」ボタンを押す
→ コンポーネントテンプレートを選ぶ（Button, Input, Badge…）
→ スタイル・サイズ・プロパティ・ドキュメントを設定
→ 「追加」→ ギャラリーに表示される
→ 繰り返して自分のデザインシステムを組み上げる
→ Storybookのようにバリアントを目視確認しながら調整
→ 完成したら Figmaにエクスポート / Markdownダウンロード
```

## 機能一覧

### Web App（ブラウザ）

| 機能 | 説明 |
|---|---|
| 空の状態 → 追加フロー | 最初は何もない状態から「+追加」でコンポーネントを組み上げる |
| テンプレートから選択 | Button / Input / Badge / Avatar / Card / Modal / Toast / Checkbox / Tabs |

| Storybookライクなギャラリー | 全バリアント・全サイズをリアルタイムプレビューで確認 |

| タイポグラフィ設定 | フォント・スケール・スペーシングの設定 |
| Figmaエクスポート | .figma.json ダウンロード → Plugin でFigmaキャンバスに生成 |
| Markdownエクスポート | .md ファイルダウンロード（ドキュメント・仕様含む） |
| localStorageで自動保存 | ログインなしでもブラウザに状態を保持 |
| ログイン同期（Phase 2） | Pluginと同じアカウントで自動同期 |
| チーム管理（v2） | メンバー招待・権限設定 |
| 影響範囲（Phase 4） | どこでコンポーネントが使われているか可視化 |

### Plugin（Figma内）

| 機能 | 説明 |
|---|---|
| コンポーネント設定・追加 | バリアント / サイズ / プロパティ / ドキュメント |
| Figmaキャンバスへの生成 | ComponentSet・変数・スタイルを自動生成 |
| 既存コンポーネントのインポート | 選択したComponentSetからプロパティを読み取りHubに追加 |

## ユーザー動線

### ① Web App単体（アカウント不要）

```
Web Appを開く（空の状態）
→「+ 追加」でコンポーネントテンプレートを選択
→ スタイル・ドキュメントを設定
→ Storybookのようにギャラリーで確認・調整
→「.figma.json をダウンロード」
→ Figma Plugin で「ファイルからインポート」
→ Figmaキャンバスに生成
```

### ② Plugin単体（アカウント不要）

```
Figmaを開く → Pluginを起動
→ コンポーネントを設定・追加 → Figmaキャンバスに生成
→ 完結（Figmaから一歩も出ない）
```

### ③ ログイン同期（アカウントあり・チーム推奨）

```
Web App / Plugin どちらかでアカウント作成
→ Plugin・Web App 両方で同じアカウントにログイン
→ どちらで変更しても自動的に同期
→ デザイナーはPluginで作業、PdM・エンジニアはWeb Appで参照・編集
```

### ④ 既存FigmaコンポーネントをHubにインポート（移行ユーザー向け）

```
Figmaキャンバスで既存のComponentSetを選択（複数可）
→ Pluginの「Figmaからインポート」ボタンを押す
→ 確認モーダルで取得内容を確認・カテゴリを手動設定
→ インポート完了 → Hubのコンポーネント一覧に追加
→ ドキュメントは空欄 → あとから編集可能
```

### ①→③ アップグレードパス

```
Web App単体で使っていたユーザーが
後からアカウントを作ってログインしたとき:

┌──────────────────────────────────────┐
│ ローカルの設定が見つかりました         │
│ どうしますか？                        │
│                                      │
│ [クラウドに保存して同期を開始する]     │
│ [クラウドの設定をインポートする]       │
└──────────────────────────────────────┘
```

## 既存FigmaコンポーネントのImport仕様

### 概要

すでにFigmaにデザインシステムを持っているチームが
既存のコンポーネントをHubに移行するための機能。

### 操作フロー

```
① Figmaキャンバスで ComponentSet を選択（複数選択可）
② Plugin の「Figmaからインポート」ボタンを押す
③ 確認モーダルで取得内容を確認・不足情報を補完
④ 「インポートする」→ Hubのコンポーネント一覧に追加
⑤ ドキュメント（定義・使用例等）はあとから編集
```

### 自動取得できる情報

| 項目 | 取得方法 | 精度 |
|---|---|---|
| コンポーネント名 | `ComponentSetNode.name` | ✅ 完全 |
| バリアント一覧 | `componentPropertyDefinitions` の VARIANT 型 | ✅ 完全 |
| バリアントごとのスタイル | 各 `ComponentNode` の fills / strokes / cornerRadius / padding / fontSize | ✅ 完全 |
| サイズ一覧 | "Size" という名前の VARIANT 型プロパティが存在すれば自動検出 | ✅ 完全 |
| BOOLEAN プロパティ | `componentPropertyDefinitions` の BOOLEAN 型 | ✅ 完全 |

### 手動入力が必要な情報

| 項目 | 理由 |
|---|---|
| カテゴリ | Figmaに概念なし（Actions / Forms / Layout 等） |
| ドキュメント | Definition / Usage / Do&Don't / Accessibility / States / Related |

## Figma同期の仕組み

### Hub → Figma（push）
- Web Appで設定した内容を .figma.json でエクスポート
- Plugin がそのファイルをインポートし、Figmaキャンバスに ComponentSet・変数・スタイルを生成

### Figma → Hub（pull）
- **Dev Mode Codegen API** でFigmaのノードプロパティを取得
- **Figma REST API**（read-only）でコンポーネント一覧・変数を取得

### 差分ステータス（Phase 2）
| ステータス | 意味 |
|---|---|
| `in sync` | HubとFigmaが一致 |
| `figma ahead` | Figmaで変更済み・Hub未反映 |
| `hub ahead` | Hubで変更済み・Figma未反映 |
| `conflict` | 両方で異なる変更あり |

---

## 接続・認証

- メールアドレス + パスワード、またはGoogleなどOAuth
- Plugin・Web App は同じ認証基盤を使用
- アカウントなしでも Plugin単体・Web App単体は使用可能
- ログイン後はlocalStorageの状態をクラウドにマージ

## 技術構成

### Web App
| 項目 | 内容 |
|---|---|
| フレームワーク | React 18 |
| バンドラー | Webpack 5 |
| 状態管理 | useState / useReducer |
| ローカル保存 | localStorage（ログインなし時） |
| ファイルDL | Blob + URL.createObjectURL |
| コンポーネントプレビュー | インライン HTML/CSS（Storybookライク） |

### Plugin
| 項目 | 内容 |
|---|---|
| 実行環境 | Figma Plugin（既存） |
| 追加API | Figma Codegen API（Dev Mode） |
| 通信 | Hub APIへのHTTPリクエスト（ログイン時のみ） |
| ローカル保存 | プラグインのclientStorage |

### Backend（ログイン同期時のみ必要）
| 項目 | 内容 |
|---|---|
| 役割 | コンフィグの保存・同期・認証 |
| 選択肢 | Supabase（最速）または 軽量Node.js API |
| DB | PostgreSQL |
| リアルタイム | Supabase Realtime または WebSocket |
